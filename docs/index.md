# Signal Fish Client (.NET)

A C# client SDK for the [Signal Fish](https://github.com/Ambiguous-Interactive/signal-fish-server)
multiplayer signaling service — rooms, lobbies, readiness, relay, heartbeats,
reconnection, spectators, authority, and WebRTC signaling.

> **Status:** early scaffold. The full documentation site lands with the
> 0.1.0 release.
